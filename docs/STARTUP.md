# Startup

Before your first reply:

1. Run `env | grep -E '^(SANDBOX_NAME|PI_)'`. If `$SANDBOX_NAME` is set, read [SANDBOX.md](SANDBOX.md). If any `PI_*` is set, read [PI.md](PI.md).
2. Read `docs/HANDOFF.md` (gitignored) and check its claims against the repo.
3. Update the user with the open issues from the last `docs/HANDOFF.md`
4. End the first reply with the list of docs you read. Don't repeat it in later replies.
